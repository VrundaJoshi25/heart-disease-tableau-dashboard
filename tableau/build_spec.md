# Tableau Public: build and publish spec

Everything here is click-by-click. Two manual steps need a human in a
browser; everything else is prepared in this repo.

## What you need (one time, ~10 minutes)

1. **Tableau Public Desktop** (free): download from
   <https://www.tableau.com/products/public/download> and install.
   (The download is bot-protected, so it cannot be scripted — this is one
   of the two manual steps.)
2. **Tableau Public account** (free): sign up at
   <https://public.tableau.com>. You will sign in inside the app when you
   publish. No one else ever needs your password.

## Data sources (already prepared)

Both live in `data/processed/tableau/`, regenerated by
`python -m src.run_analysis`:

| File | Contents | Used for |
|---|---|---|
| `tableau_feature_importance.csv` | `feature, group (Overall/Male/Female), importance, ci_low, ci_high` | Sheets 1–2 |
| `tableau_patients_labeled.csv` | all 1,025 patients, raw codes + readable labels + `age_group` | Sheets 3–4 |

Open Tableau Public Desktop → **Connect → Text file** → pick the first
CSV. Add the second CSV as a second data source (Data → New data source).

## Sheet 1 — Feature Importance by Gender (the headline view)

Data source: `tableau_feature_importance`.

1. Drag `group` to **Filters**, keep only `Male` and `Female`.
2. Drag `feature` to **Columns**, `importance` to **Rows**.
3. Drag `group` to **Color**.
4. Sort `feature` descending by `importance`.
5. Title: *"Feature importance shifts by gender (permutation, held-out test)"*.

## Sheet 2 — Overall Feature Importance

Data source: `tableau_feature_importance`.

1. Filter `group` = `Overall`.
2. `feature` to Columns, `importance` to Rows, sort descending.
3. Title: *"What drives the model, overall"*.

## Sheet 3 — Prevalence Heatmap

Data source: `tableau_patients_labeled`.

1. `cp_label` to Columns, `exang_label` to Rows.
2. Mark type: **Square**. Drag `target` to **Color**, then right-click it
   → Measure → **Average** (this is prevalence). Format as percentage.
3. Drag `target` to **Label** (Measure → Average) so each cell shows its rate.
4. Drag `sex_label` to Columns, left of `cp_label`, to split the heatmap
   by gender.
5. Title: *"Disease prevalence: chest pain x exercise angina, by gender"*.

## Sheet 4 — Prevalence by Chest-Pain Type and Gender (grouped bar)

Data source: `tableau_patients_labeled`.

1. `cp_label` to Columns, `target` to Rows → Measure → **Average**.
2. `sex_label` to **Color**.
3. Title: *"No symptom is sufficient alone"*.

## Dashboard + the 3 filters

1. New dashboard; drag in Sheets 1–4 (Sheet 1 top-left, Sheet 3 top-right,
   Sheets 2 and 4 bottom).
2. On a patient-level sheet (3 or 4), click the filter icon and add these
   three quick filters, then set each to **Apply to worksheets → All using
   this data source**:
   - `sex_label` → name it **Gender**
   - `age_group` → name it **Age group**
   - `cp_label` → name it **Chest-pain type**
   (They filter Sheets 3–4. The importance sheets come from the model
   output table and are static by design.)
3. Title the dashboard **"A Visual Analysis of Heart Disease Prevalence"**.

**Final filter list (exactly what goes on the resume/README):**
Gender, Age group, Chest-pain type.

## Publish (the second manual step)

1. **File → Save to Tableau Public As…** → sign in with your Tableau
   Public account → name it `Heart Disease Visual Analysis — Group 02`.
2. Open the public URL in a browser. **Click every filter once** and
   confirm the views respond — a dashboard that is not clickable does not
   exist.
3. Take a full-page screenshot of the published dashboard and save it as
   `tableau/dashboard_overview.png` in this repo (replaces the placeholder).
4. Paste the public URL at the top of `README.md` where marked.

## If the data ever changes

Re-run `python -m src.run_analysis`, then in Tableau: Data → refresh each
data source (or re-connect to the same two CSVs). The numbers in the
README are seed-42 numbers; they only change if the seed changes.
