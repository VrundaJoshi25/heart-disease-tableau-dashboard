# Original dashboard screenshots (course version)

These 16 images were extracted from the original course submission
(`IDV_PROJECT_PPT_GROUP02.pptx`, DS612, Autumn 2026). They document the
**first version** of the dashboard, built directly in Tableau on the raw
dataset.

The rebuilt dashboard (see `../build_spec.md`) is driven by the new
Random Forest + permutation-importance outputs instead, and is published
on Tableau Public. `../dashboard_overview.png` holds the published
version's screenshot once it is live.

Notable originals:

- `ppt_image3.png` — first-version "Gender-Based Feature Importance"
  (compare with `../../figures/fig_gender_importance.png`, the rebuilt
  version with 95% bootstrap intervals).
- `ppt_image11.png` — first-version clinical-test grouped bars
  (Rest ECG x ST slope x Thal x CA).
